Welcome, Jury! 🦸‍♂️ Here's how you can run this extension locally.

Note: We've included the .env files in the repo so you don't have to add any API keys. Just follow the steps below and you'll be flying in no time!

Issue #0: Clone the Repository

Start Here

First things first, you need the code! Clone it to your local machine:

git clone https://github.com/SyedHashirGit/Privacy-First-Browser-Agent.git cd Privacy-First-Browser-Agent

Issue #1: The Backend

Server

First, let's boot up the FastAPI server that handles the Gemini 2.5 Flash powers.

cd server python -m venv venv venv\Scripts\activate pip install -r requirements.txt uvicorn main:app --reload --port 8000

Or use Docker: docker compose up --build

Issue #2: The Extension

Frontend

Next, let's assemble the Chrome extension.

cd extension npm install npm run build

Issue #3: The Activation

Chrome
  1. Open Chrome or Edge and go to chrome://extensions
  2. Turn on Developer mode (top right corner).
  3. Click Load unpacked.
  4. Select the extension/dist folder from the cloned repo.
  5. Click the extension icon in your toolbar and select Open side panel!

Boom! 💥 You're ready to test! Type a task like "fill in the shipping address and go to checkout", pick Assist or Autopilot, and hit Start task.
