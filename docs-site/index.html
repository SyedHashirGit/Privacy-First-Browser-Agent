Welcome, Jury! 🦸‍♂️ Here's how you can run this extension locally.

Context: Since a Chrome extension cannot be deployed to a standard web URL for instant testing, we have submitted a demo video to showcase the agent in action. We created this website as our deployment link to provide you with simple, step-by-step instructions to run and demo the agent directly on your local machine.

Note: We've included the .env files in the repo so you don't have to add any API keys. Just follow the steps below and you'll be flying in no time!

Step 1: Clone the Repository

Start Here

First things first, you need the code! Check out the GitHub Repository or clone it directly to your local machine:

git clone https://github.com/SyedHashirGit/Privacy-First-Browser-Agent.git cd Privacy-First-Browser-Agent

Step 2: The Backend

Server

First, let's boot up the FastAPI server that handles the Gemini 2.5 Flash powers.

cd server python -m venv venv venv\Scripts\activate pip install -r requirements.txt uvicorn main:app --reload --port 8000

Or use Docker: docker compose up --build

Step 3: The Extension

Frontend

Next, let's assemble the Chrome extension.

cd extension npm install npm run build

Step 4: The Activation

Chrome
  1. Open Chrome or Edge and go to chrome://extensions
  2. Turn on Developer mode (top right corner).
  3. Click Load unpacked.
  4. Select the extension/dist folder from the cloned repo.
  5. Click the extension icon in your toolbar and select Open side panel!

Boom! 💥 You're ready to test! Type a task like "fill in the shipping address and go to checkout", pick Assist or Autopilot, and hit Start task.

Step 5: Testing Guide 🧪

Test Cases

Time to put the agent's superpowers to the test! Here are two test cases you can run to verify its redaction and automation abilities:

Test Case 1: The PII Shield 🛡️

  1. Open a webpage containing sensitive personal info (e.g., your photo, date of birth, phone number).
  2. Ask the agent: "Go through this page and give me a brief description of it."
  3. Observe the Magic:
    • The local vision model will intercept and redact your face, DOB, and contact details before sending data.
    • Watch the Privacy Budget to see exactly how many pixels and regions were redacted!
    • Check the Resource Meter to track local inference vs server round-trip latency.
  4. The cloud VLM will successfully describe the page without ever seeing your personal info!

Test Case 2: The Auto-Pilot ✈️

  1. Open any flight booking website (like MakeMyTrip, Google Flights, etc).
  2. Ask the agent: "Find and return the cheapest flight from Hyderabad to Bangalore for the 3rd of September 2026."
  3. Observe the Action:
    • The agent will automatically locate the search bars on the page.
    • It will autonomously type in the source, destination, and dates.
    • It will execute the search and fetch the results for you!
